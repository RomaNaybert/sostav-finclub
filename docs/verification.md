# Проверки — 21 октября 2026

## Фактически выполнено

- Python API запущен локально с настоящим PostgreSQL 18.4 (`embedded-postgres`). SQLite для результатов ниже не использовался.
- 12 тестов pytest прошли: основной сценарий, права, приватность контактов, жизненный цикл, валидация, сессии, CSRF, лимит входа, параллельные отклики, параллельные публикации и конфликтующие решения.
- Production-сборка Vite прошла. Четыре теста статической упаковки прошли.
- Ruff проверяет Python-код; Prettier форматирует фронтенд.
- В in-app браузере выполнен сценарий: Мария отправила отклик на Finflow → Алексей принял → Мария увидела «Вы в команде» и контакт автора.
- Через интерфейс создан черновик «Тестовый проект», затем опубликован и закрыт. Это тестовое объявление сохранено закрытым и не засоряет ленту.
- После обновления страницы сессия сохранилась.
- Проверены фильтр вакансий, пустой поиск, Escape в диалоге, мобильная форма, сетевая ошибка и успешная повторная попытка с сохранённым запросом.
- Проверены размеры 320, 390, 700, 701, 834, 980, 981, 1200, 1201, 1488 CSS px. В первом прогоне на 981/1200 px обнаружено переполнение из-за штампа. CSS исправлен, но повторный браузерный прогон после последнего изменения заблокирован отключением Local browser use в Work settings.
- До отключения доступа браузерных ошибок JavaScript не было. Ошибка сети создавалась намеренно для проверки восстановления.

После последних исправлений штампа, состояния загрузки следующих объявлений и разбиения React на компоненты финальная браузерная перепроверка не завершена: Local browser use отключён в Work settings. Итог визуальной проверки: **blocked**, см. `../design-qa.md`.
